# Privesk — Discord Clone

Полноценный клон Discord с собственным бэкендом, реалтайм-чатом на WebSocket, серверами, ролями,
экономикой, коллекциями и встроенным AI (генерация изображений и текста локальными моделями).

Проект полностью open-source и бесплатный. Всё работает локально, интернет нужен только для
первичной загрузки моделей и npm/pip-зависимостей.

---

## ✨ Возможности

### 👤 Аккаунты и друзья
- Регистрация и вход по email/паролю (bcrypt + JWT).
- Профиль: аватар, кастомный статус, тег, био, статус (онлайн/оффлайн).
- Поиск пользователей по нику/тегу.
- Друзья: заявки (входящие/исходящие), принятие, удаление.
- Просмотр профилей других пользователей.

### 🏠 Серверы и каналы
- Создание серверов (публичные и приватные, «только по ссылке»).
- Публичный каталог серверов (Explore) и вступление по инвайт-коду.
- Текстовые, голосовые и форум-каналы, реордер (drag-free) и настройки каналов.
- Участники сервера, никнеймы, назначение ролей.
- Бан-лист и управление банами.
- Онбординг новых участников (правила, рекомендуемые каналы, выбор ролей).

### 💬 Сообщения
- Текстовые каналы с историей, редактированием и удалением сообщений.
- Реакции (эмодзи) на сообщения.
- Ответы (reply), упоминания (@), закреплённые сообщения (pins).
- Поиск по сообщениям канала, счётчики непрочитанного.
- Индикатор «печатает…» в реальном времени.
- Markdown-рендер: код-блоки с копированием, ссылки, форматирование.

### 🧵 Треды и форумы
- Форум-каналы с постами (title + content) и тегами.
- Треды: создание из сообщения, архивирование/разархивирование, сообщения треда.

### 🛡️ Роли и права
- Создание/редактирование/удаление ролей с цветом и правами (permissions).
- Назначение ролей участникам, приоритеты ролей.
- Проверка прав на уровне API (middleware `permissions.js`).

### 📅 События и бусты
- Создание событий на сервере: название, описание, дата, канал.
- RSVP (запись на событие) и список участников.
- Буст сервера (tiers), личные и серверные бусты.

### 🔊 Голосовые каналы
- Голосовые комнаты со списком участников и состоянием (mute/deafen).
- Реалтайм-синхронизация через Socket.IO.

### ✉️ Личные сообщения
- DM-каналы 1-на-1, история, редактирование/удаление, реакции.
- Индикатор набора текста в DM.

### 🎨 Профиль, коллекции и достижения
- Коллекция эмодзи: каталог, установка/снятие эмодзи на профиль.
- Достижения с проверкой и наградами за активность.
- Приватность коллекции (публичная/скрытая).
- Просмотр чужой коллекции и профиля.

### 💰 Экономика, магазин и подписки
- Внутриигровые монеты (🪙): начисление за активность, лидерборд.
- Магазин: каталог предметов, покупка, экипировка/снятие.
- Казино: прокрут, выигрыши/проигрыши, серии, статистика, джекпоты.
- Подписки: бесплатный тариф, Privet и Privet Plus, покупка и активация.
- Промокоды (redeem-code) и разблокировка фич.

### 🤖 AI-возможности (локальные модели, без облака)
- **Генерация изображений**: Stable Diffusion (модель `segmind/small-sd`), результат сохраняется как файл.
- **Генерация текста**: Qwen2.5-1.5B-Instruct (GGUF, `Qwen/Qwen2.5-1.5B-Instruct-GGUF`, файл `qwen2.5-1.5b-instruct-q4_k_m.gguf`) через `llama-cpp-python` с потоковой выдачей (streaming).
- История AI-чатов: создание, переименование, удаление, сообщения.
- Автоперевод кириллических промптов в английский для модели изображений.
- Отдельный Python-сервис (FastAPI) с эндпоинтами `/generate`, `/generate-text`, `/generate-text-stream`, `/health`.

### 🔔 Уведомления
- Панель уведомлений и упоминаний, отметка прочитанного по каналу.
- Бейджи непрочитанного на серверах/каналах/DM.

### 🛠️ Админ-панель / Режим разработчика
- Панель разработчика с разделами: отладка, консоль, API-тестер, хранилище, звуки, тема,
  **язык**, пользователь, сервер, сеть, фичи, инструменты.
- **Управление пользователями** (для админов): поиск, смена роли (`user`/`moderator`/`admin`),
  начисление монет, удаление.
- **Вход в чужой аккаунт** (impersonation) с баннером «Вернуться» обратно в админа.
- Кастомная тема (акцент, размер шрифта, скругления, скорость анимаций), экспорт/импорт настроек.

### 🌍 Локализация (11 языков)
Интерфейс переведён на 11 языков с переключением на лету (сохраняется в `localStorage`):

RU · EN · UK · DE · FR · ES · IT · PT · PL · TR · ZH

Переключатель доступен на странице входа и в админ-панели (раздел «Язык»).

## 🚀 Установка и запуск

### Быстрый старт
1. **Установка зависимостей**: запустите `setup.bat` (Windows).
   Скрипт поставит pip-зависимости (`requirements.txt`), `npm install` во frontend и backend,
   скачает модели (`setup_models.py`: `segmind/small-sd` и `Qwen/Qwen2.5-1.5B-Instruct-GGUF`).
2. **Запуск**: запустите `start.ps1` (или `python start.py`).
   `start.py` проверит окружение, при необходимости доустановит недостающие пакеты и поднимет
   бэкенд, AI-сервис и фронтенд.
3. Откройте **http://localhost:5173**.

### Ручной запуск
```powershell
# 1) Модели (однократно, ~6 ГБ)
python setup_models.py

# 2) Backend (порт 3001)
cd backend
npm install
npm start

# 3) AI-сервис (порт 8000)
cd ../ai-service
pip install -r ../requirements.txt
python main.py

# 4) Frontend (порт 5173, проксирует /api и /socket.io на 3001)
cd ../frontend
npm install
npm run dev
```

Порядок запуска моделей занимает 40–60 секунд. AI-сервис грузит изображение-модель и текстовую модель.

## 🗄️ База данных

Используется SQLite через `sql.js`, файл `backend/discord.db`. Схема и миграции — в
`backend/database.js` (таблицы пользователей, серверов, каналов, сообщений, ролей, друзей,
коллекций, магазина, событий, бустов, AI-чатов и т.д.). Миграции выполняются автоматически при
старте.

---

## 🔒 Безопасность

- Пароли хранятся только в виде bcrypt-хэшей и **никогда не отображаются** в интерфейсе.
- Все защищённые маршруты требуют JWT (`authMiddleware`).
- Админ-эндпоинты дополнительно проверяют роль `admin`.
- Для продакшена обязательно задайте собственный `JWT_SECRET`.
